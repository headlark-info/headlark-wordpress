# headlark-wordpress
Headlark for WordPress: titles, meta descriptions, link previews, JSON-LD and alt text, written once when you publish.

The plugin is in [`headlark/`](headlark/). It is also listed on WordPress.org once approved. Docs: https://headlark.com/docs/wordpress.html

Contributing: run `git config core.hooksPath .githooks` once per clone; the pre-commit hook uses [gitleaks](https://github.com/gitleaks/gitleaks) to block commits that contain secrets. Report security issues privately via GitHub's "Report a vulnerability".
